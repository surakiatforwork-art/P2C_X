# P2C_X v0.9.1

Stable release for Android 8.0+ and LSPosed with modern libxposed API 102.

- ปรับหน้าหลักและหน้าอัปเดตให้อ่านง่าย พร้อมแสดงขั้นตอนและความคืบหน้าดาวน์โหลด
- เช็ก ดาวน์โหลด และติดตั้งอัปเดตจาก GitHub Releases ภายในแอป ผู้ใช้เลือกอัปเดตเอง ไม่มีการบังคับ
- ตรวจ SHA-256 เมื่อ GitHub ระบุไว้ พร้อมตรวจแพ็กเกจ ลายเซ็น และ versionCode ก่อนเปิดตัวติดตั้ง Android
- ลงทะเบียนด้วยชื่อเล่นและอนุมัติผู้ใช้ใหม่อัตโนมัติ รวมผู้ใช้เดิมที่รออนุมัติ โดยยังคงการบล็อกและการปิดระบบส่วนกลาง
- รวมการปรับแกลเลอรีและเครื่องมือแก้ไขภาพ: จำอัลบั้ม/ตำแหน่งเลื่อนและค่าปรับภาพแยกแต่ละแอป หมุนภาพ และสัดส่วนแนะนำเมื่อมีข้อมูลกล้องรองรับ

ติดตั้ง APK ทับเวอร์ชันเดิมได้โดยไม่ต้องล้างข้อมูล หลังอัปเดตให้ปิดแล้วเปิดแอปเป้าหมายใหม่เพื่อให้ LSPosed โหลดโมดูลล่าสุด

APK นี้เป็น release build (ไม่เปิด debugging) และใช้ใบรับรองเดิมเพื่อรองรับการอัปเดตทับ
